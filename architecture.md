- **Frontend:** React 19 + Vite + Tailwind v4, `react-markdown`, `DOMPurify`. Built via `node:20-alpine` → `nginx:alpine`. `VITE_API_URL=/api` (nginx proxies to `backend:8000`). No secrets at build.
- **Backend:** FastAPI `app/main.py:22` lifespan, `RequestIdMiddleware`, CORS, structured logs. Routes: `health`, `sessions`, `chat` (SSE). Services: `database`, `embeddings`, `llm`, `retrieval`, `prompts`, `artifacts`, `agent_router`. Skills: `ship30/SKILL.md`.
- **DB:** `pgvector/pgvector:pg16`, `pgdata` volume, healthcheck `pg_isready`. Single tenant now; schema pluggable to `tenant_id`.
- **Ollama:** not in compose by default (evaluator runs host Ollama). Backend reaches via `host.docker.internal:host-gateway`. Alternative: add `ollama` service with `ollama/ollama` and volume.

## Database schema (Alembic `001_initial.py`)

```sql
CREATE EXTENSION vector, pgcrypto;

sessions(id TEXT PK, title TEXT, user_id TEXT idx, created_at TIMESTAMPTZ, updated_at TIMESTAMPTZ)
messages(id TEXT PK, session_id FK idx, role TEXT, content TEXT, meta JSONB, created_at TIMESTAMPTZ)
  idx (session_id, created_at)

documents(id TEXT PK, source_path TEXT UNIQUE, title TEXT, guest TEXT, doc_type TEXT, word_count INT, checksum TEXT, created_at TIMESTAMPTZ)
chunks(id TEXT PK, document_id FK idx, ordinal INT, content TEXT, embedding vector(384), tsv TSVECTOR, token_count INT, model TEXT, created_at TIMESTAMPTZ)
  idx (document_id, ordinal)
  trigger trg_chunks_tsv BEFORE INSERT/UPDATE -> to_tsvector('english', content)
  idx hnsw ix_chunks_embedding_hnsw ON (embedding vector_cosine_ops) WITH (m=16, ef_construction=64)
  idx gin ix_chunks_tsv ON (tsv)
```

- `vector(384)` strict to `all-MiniLM-L6-v2`. Changing dims requires `ALTER TYPE` + reingest.
- `tsv` generated by trigger, not app code; bulk `COPY` still triggers. `websearch_to_tsquery` handles user input safely.
- `updated_at` is app-written; `created_at` server `NOW()`.

## Component boundaries

- **Config (`app/config.py:15`):** `BaseSettings` from env/.env, `llm_provider` literal, `cors_origins_list`, `provider_status()`.
- **Database (`services/database.py:4`):** single `create_async_engine(pool_pre_ping)`, `SessionLocal(expire_on_commit=False)`, `get_db()` yields with commit/rollback.
- **Embeddings (`services/embeddings.py`):** `local` (SentenceTransformer normalized) primary; `ollama`/`openai` fallbacks via HTTP/API. Sync `embed_texts_sync` offloaded via `run_in_executor` to avoid blocking loop.
- **LLM (`services/llm.py`):** Pi-wrapper shape — `generate(messages)` + `stream(messages)` + `ollama_health()`. Each provider has chat + stream; Ollama uses `/api/chat` stream true with temp 0.2. No SDK pin; lean http keeps deps low (Pi `pi_coding_agent` can be added via `HarnessConfig` without refactor).
- **Retrieval (`services/retrieval.py:17`):** hybrid in one SQL: `vector_hits` (HNSW `<=>`) + `keyword_hits` (`ts_rank_cd` + `websearch_to_tsquery`) → `fused` via RRF `1/(60+rnk)` → join → limit. `qvec` embedded *before* DB conn held. Falls back to `VECTOR_ONLY_SQL` if no keyword hits.
- **Prompts (`services/prompts.py`):** `GROUNDED_SYSTEM` enforces citations + abstain; `SHIP30_SYSTEM` encodes headline/hook/1-3-1/bullets; `ARTIFACT_SYSTEM_*` branches markdown/html with safety constraints.
- **Router (`services/agent_router.py`):** keyword regex for `ship30`/`artifact`; explicit `mode` wins.
- **Artifacts (`services/artifacts.py`):** `sanitize_html` extracts `<style>` safely, `bleach.clean` + `CSSSanitizer` (tinycss2), blocks `script/iframe/form/on*/javascript:/@import/url()/fixed`, re-injects only safe styles, link `noopener`.

## Ingestion / retrieval flow

1. **Vendor:** `backend/data/source/index.json` (schema 2.0, 50 podcasts +10 newsletters) + md files. Checksum `md5`.
2. **Ingest (`scripts/ingest.py:234`):** load index → for each file parse frontmatter → `RecursiveCharacterTextSplitter(800/100)` → prepend `"{title} — guest: {guest}"` → batch 32 → `SentenceTransformer.encode(normalize)` → `psycopg2` inserts documents/chunks → trigger fills `tsv`. `--reset` truncates; incremental skips unchanged checksum.
3. **Query:** embed query (threadpool) → RRF hybrid SQL (candidate 30 → top 8) → confidence = `rrf_score` → if `rrf < 0.10` or no rows → abstain; else build `GROUNDED/Ship30/Artifact` messages (last 6–8 history) → stream LLM → post-process artifacts (extract fenced ` ```html ```, sanitize, emit `artifact` event) → persist `assistant` message with `meta.sources/artifact`.
4. **Evaluation:** RRF math unit tests (`test_retrieval.py:1`), prompts tests, future eval harness can compute recall@8 + citation rate vs gold set.

## Agent routing

- **Skill boundary:** `app/skills/ship30/SKILL.md` defines headline formula, hook types, 1/3/1, formatting, citation contract. Routed via `route_intent`.
- **Pi bridge:** `llm.py` is the Pi-equivalent provider abstraction (`model.provider` / `model.id` → `ollama`/`anthropic`/`openai`). `stream` is the headless-session equivalent (`pi_coding_agent` would be `create_agent_session` + `session.prompt` streaming `MessageUpdateEvent`).
- **Failure:** missing Anthropic key → `RuntimeError` surfaces as SSE `error` rather than 500.

## Security — artifact viewer

| Threat | How we contain | What we permit | What we block |
|--------|----------------|----------------|---------------|
| XSS in model HTML | Server `bleach` + client `DOMPurify`, iframe sandbox | `h1-h6,p,ul,table,style,code` etc., CSS allowlist, `href` with `noopener` | `script,iframe,object,embed,form,meta,on*`, `javascript:`, `url()`, `@import`, `position:fixed`, `http-equiv` |
| Cookie exfil | `sandbox="allow-scripts allow-popups"` **without** `allow-same-origin`; `referrerPolicy="no-referrer"`; no session cookies on viewer origin | Scripts can run to make interactive prototypes | DOM/cookies of parent origin unreachable (null origin) |
| Network exfil | CSP via allowlist + sandbox, no `connect-src` in served HTML; logs report `csp-violation` (future) | `img-src data:https:` only via allowlist | External fetch/AJAX blocked, `frame-ancestors` pinned to app origin |
| Oversized payload | `validate_artifact` caps 200k chars, server returns warnings | — | — |

**Why `allow-scripts` without `allow-same-origin` is the boundary:** sandbox with both is same as no sandbox. We keep `allow-scripts` for interactive artifacts, but null origin isolates from `app` origin even if script tries to read `document.cookie`.

## Deployment topology

- **Docker (target):** `docker-compose.yml:9` → `postgres:5432` (pgvector) + `backend:8000` + `frontend:80` (nginx proxies `/api`). Volumes `pgdata`, `backend-data`. Healthchecks on postgres + backend. `extra_hosts: host.docker.internal:host-gateway` for Ollama.
- **Local:** `alembic upgrade head` + `uvicorn` + `npm run dev` proxy. `DATABASE_URL` flips to `localhost`.
- **Managed DB alt:** Supabase/Railway — set `DATABASE_URL`, remove `postgres` service from compose; HNSW creation still via migration.

## Config & toggle behavior

- Single source `backend/.env` / `backend/.env.example`. Docker compose `env_file` + `environment` override `DATABASE_URL` to `postgres:5432`. `LLM_PROVIDER` is read once at startup; `/api/config` echo for UI.
- **Fallback:** no auto-switch. If selected provider fails → `ollama_health` false → chat returns SSE `error` with remediation string; UI badge stays amber, user can change provider env and restart.

## Observability & resilience

- **Logs:** `logging.basicConfig` to stdout, `level=LOG_LEVEL`, `%(asctime)s | %(levelname)s | %(name)s | %(message)s`, includes `request_id` via `RequestIdMiddleware`. Per-request: `latency_ms`, `confidence`, `mode`, `provider`, `retrieval_count` in `messages.meta`.
- **Health:** `GET /api/health` does `SELECT 1` + session count + Ollama GET `/api/tags`. `db_ok` false → `status: degraded`, not 500.
- **Resilience:** missing Anthropic/OpenAI key → `503` detail; Ollama down → SSE `error`; empty retrieval → deterministic abstain without LLM call; DB conn failure → rollback + `500` with `Internal server error` handler; embedding failure → `RuntimeError` surfaces.
- **Rate:** Ollama/stream timeouts 90–120s; frontend `AbortController` can cancel stream.
